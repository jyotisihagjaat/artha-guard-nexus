# ARTHA GUARD — NEXUS / MONEY OS

A responsive financial-awareness hackathon prototype.

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server, or double-click it to open in a browser.
4. No Python, npm, package installation, API key, or backend is required.

## Included modules
- Explainable local suspicious-message pattern scanner and URL heuristic checker
- Sample spending dashboard and safety academy
- Financial Health Index with animated gauge and transparent heuristic factors
- Expense heatmap calendar with manual entries
- What-if monthly investment time machine and graph
- 50/30/20 budget planner
- Savings goal tracker with jar visual and months estimate
- Subscription tracker (manual renewal dates; no push notifications)
- Split bill calculator
- EMI and SIP estimators
- Category donut chart and CSS 3D Money City visual
- Savings streak, badges, levels and 30-day mindful-spending check-ins

## Data & limitations
User-entered demo values are stored locally in browser `localStorage`; they are not sent to a server. Clear browser site data to reset them. The Financial Health Index is an educational heuristic, not a credit score, loan assessment or guarantee. SIP/time-machine returns are hypothetical and not guaranteed; this is not investment advice. EMI outputs are estimates and exclude fees, taxes and lender-specific terms. Subscription renewals are displayed in the app only; no notifications are sent. Scam and URL tools use local patterns only and do not query live threat-intelligence databases. Money City is a lightweight CSS 3D-style visual, not a full 3D engine or bank integration.

## Presentation note
Use fictional or anonymised data in a public demo. Never enter OTPs, passwords, UPI PINs, bank credentials or private financial details.
